# 🌐 Cloud Web App

<p align="center">
  🚀 A scalable cloud-based web application built with Node.js, Supabase, and modern web technologies  
</p>

---

## ✨ Overview

This project is a **full-stack cloud web application** designed to demonstrate real-world backend integration, scalable architecture, and responsive frontend design.

It leverages **Node.js for backend logic** and **Supabase for cloud database services**, making it efficient and production-ready.

---

## 🚀 Features

* ⚡ Fast & responsive UI
* ☁️ Cloud-powered backend
* 🔐 Secure database handling with Supabase
* 📊 Real-time data updates
* 📱 Mobile-friendly interface
* 🔄 REST API integration

---

## ⚙️ Installation & Setup

```bash
# Clone repository
git clone https://github.com/bhattsana/cloud-web-app.git

# Navigate into project
cd cloud-web-app

# Install dependencies
npm install

# Run the server
node index.js
```
